# Satyavamsi Portfolio

Personal portfolio for **Kurasala Jayadeva Satyavamsi**, focused on machine learning, data science and practical AI projects.

## Featured project

### Credit Default Risk Intelligence
End-to-end classification project with model comparison, 5-fold cross-validation, threshold tuning, explainability, fairness analysis, GitHub Actions and a live Streamlit app.

- **Live demo:** https://credit-default-risk-intelligence-69rgyefwwpr9jcnefo2ism.streamlit.app
- **Source:** https://github.com/jayadevuha-ui/credit-default-risk-intelligence
- **Test ROC-AUC:** 0.7800
- **Test PR-AUC:** 0.5525
- **Recall at tuned threshold:** 0.5818
- **F1 at tuned threshold:** 0.5456

## Stack

HTML, CSS and JavaScript. No build step or framework is required, so the site can be hosted directly with GitHub Pages.
